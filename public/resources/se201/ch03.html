3.1 栈的定义与抽象数据类型

栈（Stack）是限定仅在表尾进行插入和删除操作的线性表。表尾称为栈顶（top），表头称为栈底（bottom）。不含元素的空表称为空栈。

  • 核心特性：后进先出（LIFO, Last In First Out）；
  • 基本运算：InitStack、Push、Pop、GetTop、StackEmpty；
  • n 个不同元素依次进栈，合法出栈序列数为卡特兰数 C(2n,n)/(n+1)。
高频考点：给定入栈序列 1,2,3,4，判断出栈序列 3,4,2,1 是否合法？（合法）4,3,1,2 呢？（不合法）

3.2 顺序栈的实现

#define MAXSIZE 100 typedef struct { ElemType data[MAXSIZE]; int top; // 栈顶指针，空栈时为 -1 } SqStack; // 入栈 int Push(SqStack *S, ElemType e) { if (S->top == MAXSIZE - 1) return 0; // 栈满 S->data[++S->top] = e; return 1; } // 出栈 int Pop(SqStack *S, ElemType *e) { if (S->top == -1) return 0; // 栈空 *e = S->data[S->top--]; return 1; }

3.3 栈的典型应用

  • 括号匹配：扫描表达式，左括号入栈，遇右括号弹栈匹配；
  • 表达式求值：中缀转后缀（调度场算法）+ 后缀表达式求值；
  • 递归消除：函数调用栈帧、汉诺塔的非递归实现；
  • 浏览器前进/后退：两个栈分别保存历史与前进记录。

3.4 队列的定义与实现

队列（Queue）是只允许在表的一端（队尾）插入、另一端（队头）删除的线性表，具有先进先出（FIFO）特性。

顺序队列的"假溢出"问题：rear 到达数组末尾但队头仍有空位。解决方案是采用循环队列，通过取模运算实现数组首尾相接。

// 循环队列：牺牲一个存储单元区分队空/队满 #define MAXQSIZE 100 typedef struct { ElemType data[MAXQSIZE]; int front; // 队头指针 int rear; // 队尾指针（指向下一插入位置） } SqQueue; // 队空条件：front == rear // 队满条件：(rear + 1) % MAXQSIZE == front // 队列长度：(rear - front + MAXQSIZE) % MAXQSIZE

3.5 栈与队列对比

对比项栈（Stack）队列（Queue）
操作端仅栈顶队尾插入、队头删除
特性后进先出 LIFO先进先出 FIFO
典型应用函数调用、撤销操作、DFS任务调度、消息缓冲、BFS
顺序实现难点栈满判断假溢出 → 循环队列

本章小结

栈与队列是操作受限的线性表。栈的核心是"后进先出"，广泛应用于递归实现、表达式求值与深度优先遍历；队列的核心是"先进先出"，是任务调度与广度优先遍历的基础。循环队列通过牺牲一个存储单元解决假溢出问题，是考试与面试的高频考点。
