核心知识点

  • 快速排序平均时间复杂度 O(nlogn)，最坏 O(n²)，原地排序但不稳定；
  • 归并排序稳定保持 O(nlogn)，需要 O(n) 辅助空间，是外部排序的基础；
  • 基准元素选择策略：固定首元素 vs 随机选择 vs 三数取中；
  • 小规模子数组（n≤16）切换插入排序可提升实际性能约 10%~20%。

演示代码

int partition(int a[], int low, int high) { int pivot = a[low]; while (low < high) { while (low < high && a[high] >= pivot) high--; a[low] = a[high]; while (low < high && a[low] <= pivot) low++; a[high] = a[low]; } a[low] = pivot; return low; } void quickSort(int a[], int low, int high) { if (low < high) { int mid = partition(a, low, high); quickSort(a, low, mid - 1); quickSort(a, mid + 1, high); } }
