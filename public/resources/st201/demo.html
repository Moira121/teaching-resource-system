核心知识点

  • 分层框架的核心收益：用例可读性 ↑、重复代码 ↓、页面变更时只需改页面对象层；
  • conftest.py 的 fixture 是 pytest 依赖注入的灵魂，scope 参数控制复用粒度；
  • 测试数据与测试逻辑分离是数据驱动的前提，推荐 YAML 管理；
  • CI 集成的关键：无头模式运行、失败产物（截图/日志/报告）作为构件归档。

演示代码

# conftest.py —— WebDriver 固件 import pytest from selenium import webdriver @pytest.fixture(scope="session") def driver(): options = webdriver.ChromeOptions() options.add_argument("--headless=new") d = webdriver.Chrome(options=options) yield d d.quit() # test_login.py —— 数据驱动用例 import pytest, yaml data = yaml.safe_load(open("login_data.yaml", encoding="utf-8")) @pytest.mark.parametrize("case", data) def test_login(login_page, case): login_page.login(case["user"], case["pwd"]) assert login_page.get_tip() == case["expect"]
