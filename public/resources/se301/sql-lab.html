SQL 上机实验指导书文档

课程：数据库系统原理（SE301）  |  2025-2026-1  |  资源编号：R008

实验总体说明

本课程共安排 4 次 SQL 上机实验（每次 2 学时），实验环境为 MySQL 8.0 + MySQL Workbench。实验数据库统一使用教务管理系统（jwgl）样例库，含 student、course、sc、teacher、department 五张表。请提前在个人电脑完成环境安装并导入建库脚本。

实验 1：数据定义与单表查询（2 学时）

实验目的：掌握 CREATE TABLE、约束定义与 SELECT 基本查询。

实验内容与步骤

  1. 连接数据库，创建 jwgl 库并切换；
  2. 按给定表结构创建 student 表（含主键、非空、默认值约束）；
  3. 插入 10 条样例数据；
  4. 完成查询练习：全体学生信息、按姓氏模糊查询、按入学年份分组统计；
  5. 练习 ALTER TABLE 增加/删除列。

参考示例

CREATE TABLE student ( sno CHAR(10) PRIMARY KEY, sname VARCHAR(20) NOT NULL, gender CHAR(2) DEFAULT '男', birthday DATE, dno CHAR(4) ); -- 查询姓'张'的学生 SELECT sno, sname FROM student WHERE sname LIKE '张%';

验收要求

  • 5 张表创建语句正确，约束完整；
  • 10 道查询练习题全部在 Workbench 中运行通过并截图。

实验 2：连接查询与嵌套查询（2 学时）

实验目的：掌握等值连接、外连接、IN/EXISTS 嵌套查询。

实验内容与步骤

  1. 三表连接：查询学生姓名、课程名与成绩；
  2. 左外连接：查询所有课程及其选修人数（含无人选修的课程）；
  3. IN 子查询：查询选修了"数据库"课程的学生姓名；
  4. EXISTS 相关子查询：查询选修了全部课程的学生；
  5. 对比 NOT IN 与 NOT EXISTS 在含 NULL 时的行为差异并记录。

参考示例

-- 查询每门课程的平均分并降序排列 SELECT c.cname, AVG(sc.grade) AS avg_grade FROM sc JOIN course c ON sc.cno = c.cno GROUP BY c.cno, c.cname ORDER BY avg_grade DESC;

验收要求

  • 8 道练习题运行结果正确；
  • 在实验报告中解释 NOT IN 遇到 NULL 返回空集的原因。

实验 3：视图、索引与数据更新（2 学时）

实验目的：掌握视图创建与更新限制、索引创建与执行计划分析。

实验内容与步骤

  1. 创建视图 v_avg：每个学生的学号、姓名、平均成绩；
  2. 尝试对视图执行 UPDATE，观察并记录更新限制；
  3. 在 sc(grade) 上创建索引，用 EXPLAIN 对比创建前后的查询计划；
  4. 批量更新：将"数据库"课程成绩整体上调 5 分（不超过 100）；
  5. 事务练习：显式开启事务执行更新，验证 ROLLBACK 效果。

参考示例

CREATE VIEW v_avg AS SELECT s.sno, s.sname, AVG(sc.grade) AS avg_grade FROM student s JOIN sc ON s.sno = sc.sno GROUP BY s.sno, s.sname; EXPLAIN SELECT * FROM sc WHERE grade > 90;

验收要求

  • 视图可正常查询且更新限制解释正确；
  • EXPLAIN 输出截图中能看到索引命中（key 列非 NULL）。

实验 4：综合实验：迷你选课系统（2 学时）

实验目的：综合运用 DDL/DML/视图/事务完成小型数据库应用设计。

实验内容与步骤

  1. 自行设计并创建"选课系统"数据库（不少于 4 张表，含外键）；
  2. 实现选课登记（含事务：校验容量 + 插入选课记录）；
  3. 实现统计视图：各班选课率排行；
  4. 编写 3 个业务查询 SQL 并附设计说明；
  5. 两人一组互评：检查对方数据库的约束完整性与范式合理性。

验收要求

  • 现场演示选课登记事务（成功与回滚各一次）；
  • 提交完整建库脚本与查询脚本，命名规范。

实验报告要求

  • 每次实验后 1 周内提交实验报告（PDF），含实验步骤、运行截图、问题与解决记录；
  • 报告第 4 节必须包含"思考与讨论"：分析实验中遇到的至少 1 个报错及排查过程；
  • 实验报告占总评的 30%，抄袭一经发现当次实验记 0 分。
