软件测试技术-实验指导书文档

课程：软件测试技术（ST101）  |  2025-2026-1  |  资源编号：R013

实验总体说明

本课程共 4 次实验（每次 2 学时），围绕"三角形分类"经典案例与 Web 应用展开，覆盖单元测试、黑盒测试设计、自动化测试与性能测试。实验环境：JDK 17 + JUnit 5 + Selenium + JMeter。

实验 1：JUnit 单元测试入门（2 学时）

实验目的：掌握 JUnit 5 测试框架的基本使用与断言机制。

实验内容与步骤

  1. 创建 Maven 项目，引入 junit-jupiter 依赖；
  2. 编写被测类 Triangle.classify(a,b,c)：判断等边/等腰/普通/非三角形；
  3. 为 classify 编写不少于 12 个测试用例；
  4. 使用 @ParameterizedTest + @CsvSource 改造重复用例；
  5. 运行测试并查看 Jacoco 覆盖率报告（行覆盖 ≥ 90%）。

参考示例

@ParameterizedTest @CsvSource({ "3,4,5, 普通三角形", "3,3,3, 等边三角形", "3,3,5, 等腰三角形", "1,2,3, 非三角形", "0,4,5, 非法输入" }) void testClassify(int a, int b, int c, String expected) { assertEquals(expected, Triangle.classify(a, b, c)); }

验收要求

  • 12 个用例全部通过；
  • Jacoco 报告显示 Triangle 类行覆盖率 ≥ 90%。

实验 2：黑盒测试用例设计（2 学时）

实验目的：掌握等价类划分与边界值分析两种方法。

实验内容与步骤

  1. 对 classify 方法进行等价类划分：画出有效/无效等价类表；
  2. 基于等价类表设计测试用例（强一般等价类）；
  3. 对三条边取值范围 [1,200] 进行边界值分析：4n+1 个用例；
  4. 对比两种方法设计出的用例集，分析查错能力差异；
  5. 引入一个含缺陷的实现版本，用两组用例分别测试并记录发现缺陷数。

验收要求

  • 等价类表格式规范、覆盖输入域；
  • 边界值用例数量与选取点正确（含略小于/等于/略大于边界）。

实验 3：Selenium Web 自动化测试（2 学时）

实验目的：掌握 Web 元素定位与 Page Object 模式。

实验内容与步骤

  1. 搭建 Selenium + ChromeDriver 环境；
  2. 对教学平台登录页编写自动化脚本：正例 + 3 个反例；
  3. 使用显式等待 WebDriverWait 替代 Thread.sleep；
  4. 按 Page Object 模式重构：LoginPage 类封装元素定位；
  5. 加入断言与失败截图（TakesScreenshot）。

参考示例

WebDriverWait wait = new WebDriverWait(driver, Duration.ofSeconds(10)); WebElement btn = wait.until( ExpectedConditions.elementToBeClickable(By.id("loginBtn")) ); btn.click();

验收要求

  • 4 个登录场景脚本全部运行通过；
  • 代码符合 Page Object 分层，无硬编码等待。

实验 4：JMeter 性能测试（2 学时）

实验目的：掌握并发压测计划的设计与结果分析。

实验内容与步骤

  1. 创建线程组：50 并发、Ramp-up 10 秒、循环 20 次；
  2. 添加 HTTP 请求取样器（课程列表接口）与响应断言；
  3. 添加聚合报告、响应时间图、吞吐量监听器；
  4. 执行压测，记录平均响应时间、90% 分位、错误率；
  5. 调整并发到 100/200，观察性能拐点并撰写分析结论。

验收要求

  • 压测计划配置正确并执行成功；
  • 报告中给出性能拐点并发数与可能瓶颈分析。

实验报告要求

  • 每次实验提交测试设计文档 + 源代码 + 运行截图；
  • 实验 2 与实验 4 需提交对比分析（不少于 300 字）；
  • 实验成绩 = 现场验收 50% + 报告质量 50%。
