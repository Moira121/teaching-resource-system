一、奈奎斯特准则（无噪声信道）

1924 年奈奎斯特（Nyquist）推导出：在理想低通信道中，无码间串扰的最高码元传输速率受带宽限制。

奈奎斯特第一准则 公式

若信道带宽为 B（Hz），则无码间串扰的最大码元速率为：

  • R_Bmax = 2B （码元/秒，波特）
  • 物理含义：理想低通信道每赫兹带宽每秒最多传输 2 个码元；
  • 若每个码元携带 M 进制信息（log₂M 比特），则最大信息速率 R_b = 2B·log₂M (bit/s)。

推导要点 推导

从抽样定理与 sinc 函数的正交性出发：

  • 理想低通信道的冲激响应为 h(t) = sinc(2Bt)，其在码元间隔 T = 1/(2B) 的整数倍处取值为零；
  • 以 R_B = 2B 的速率发送时，抽样时刻其他码元的响应均为零 → 无码间串扰；
  • 超过 2B 时抽样点不再正交，码间串扰不可避免。

二、香农公式（有噪声信道）

1948 年香农（Shannon）在《通信的数学理论》中给出了加性高斯白噪声（AWGN）信道的容量上限。

香农信道容量公式 公式

带宽为 B、信噪比为 S/N 的连续信道，其信道容量为：

  • C = B·log₂(1 + S/N) (bit/s)
  • 若用分贝表示信噪比：(S/N)dB = 10·lg(S/N)，注意计算时须先换算回功率比；
  • 当信噪比趋于无穷大，C 也趋于无穷；但带宽一定时，容量增长受 log 关系约束。

香农公式的意义与推论 理解

香农公式给出了可靠通信的理论极限，是信道编码理论的基础：

  • 只要信息速率 R < C，总存在某种编码使误码率任意小；反之 R > C 时不可能可靠传输；
  • 带宽与信噪比可以互换：带宽有限时可用提高信噪比弥补（卫星通信）；
  • 扩展形式：C = B·log₂(1 + S/(n₀B))，当 B→∞ 时 C→1.44·S/n₀（极限容量）。

三、典型例题

以下两道例题覆盖本材料核心考点，建议先独立求解再对照解析。

例题 1：无噪声信道 计算

某理想低通信道带宽 3 kHz，采用 8 进制码元传输，求最大信息传输速率。

  • 解：R_b = 2B·log₂M = 2×3000×log₂8 = 2×3000×3 = 18000 bit/s = 18 kbps。

例题 2：香农公式 计算

电话信道带宽 3.4 kHz，信噪比 30 dB，求信道容量；若信噪比提高到 40 dB，容量增加多少？

  • 30 dB → S/N = 10³ = 1000，C = 3400×log₂(1001) ≈ 3400×9.97 ≈ 33.9 kbps；
  • 40 dB → S/N = 10⁴，C = 3400×log₂(10001) ≈ 3400×13.29 ≈ 45.2 kbps；
  • 信噪比提高 10 dB，容量仅增加约 11.3 kbps，体现 log 增长的"边际递减"。
