# 爱教学平台 · 用户使用手册

本手册面向**教研室主任**、**教学督导**、**教师**三类用户，介绍平台的登录、课程查询、教学资源浏览、教学评价查阅等日常操作。

平台地址：`http://localhost:3000`（部署后请使用实际访问地址）

## 1. 登录系统

### 1.1 选择角色

打开平台首页，你会看到三个角色卡片：

| 角色 | 入口页面 | 适用人群 |
|------|----------|----------|
| 📋 教研室主任 | `director.html` | 负责全院课程统筹管理 |
| 👨‍🏫 教师 | `teacher.html` | 任课教师，仅能看到本人课程 |
| 🔍 教学督导 | `supervisor.html` | 负责听课、评价的督导人员 |

点击角色卡片即可选中。

### 1.2 教师身份选择

如果选择了「教师」角色，下方会出现一个**教师身份选择下拉框**，请从中选择你本人。系统中预置了 7 位教师身份，每位对应不同的课程。

主任与督导角色**不需要选择教师身份**，直接点击「进入系统」即可。

### 1.3 退出登录

点击右上角的「退出」按钮，系统会清除当前登录状态并回到角色选择页。

## 2. 教研室主任使用指南

入口：首页 → 选择「教研室主任」 → 进入系统

### 2.1 课程总览

登录后默认进入课程列表页，你可以：

- **查看全院全部课程**：默认列出所有学期、所有学院、所有教研室的课程
- **多条件筛选**：按学期、学院、教研室、课程类别（必修/选修）组合过滤
- **关键词搜索**：输入课程名称、课程代码或授课教师姓名，支持模糊匹配
- **分页浏览**：通过底部分页器切换，每页最多 50 条

### 2.2 课程详情

点击任意一行课程，弹窗会显示该课程的完整信息：

- 基本信息：课程代码、学分、学时、授课时间、授课教室
- 教师信息：授课教师、职称、所属学院
- 📎 **教学资源区**：只读浏览该课程配套的课件 / 文档 / 视频 / 链接 / 作业

> 💡 主任对课程资源仅有只读权限，无法新增、修改或删除资源。

### 2.3 全院统计数据

页面顶部的统计卡片展示全院汇总：

- 课程总数、教师总数、覆盖学生总人次、总学时数

### 2.4 导出评价汇总表

页面顶部有「📊 导出评价汇总表（CSV）」按钮：

- 点击即可下载全部课程的评价统计汇总表（Excel 可直接打开）
- 表格包含：课程代码、课程名称、授课教师、学期、学院、评价条数、总均分、学生均分、督导均分、同行均分
- 支持按学期或学院筛选后再导出

### 2.5 课程资源数量统计

主任专属接口，可查看每门课程的教学资源数量排行，了解各教研室资源建设情况。

## 3. 教学督导使用指南

入口：首页 → 选择「教学督导」 → 进入系统

### 3.1 筛选听课对象

督导的主要任务是确定本学期的听课对象。你可以：

- **按教师筛选**：从教师名录中选定某位教师
- **按课程筛选**：结合学期、学院、教研室、课程类别进一步缩小范围
- **关键词搜索**：快速定位目标课程

### 3.2 查看课程资源（只读）

课程详情弹窗中的 📎 **教学资源区**对督导完全开放，但**仅有只读权限**：

- 可以浏览、点击打开资源链接
- 不能新增、修改或删除任何资源（按钮不会出现或操作会被拒绝）

> 🔒 督导写操作严格禁止，服务端会拦截并返回 403 错误。

### 3.3 查阅历史评价记录

页面提供「评价记录」查询功能，可查看全校课程的历史教学评价：

- **全部查阅**：默认返回所有评价记录（按学期倒序，每页显示 500 条）
- **按课程过滤**：输入课程 ID（如 C001）查看该课程所有历史评价
- **按学期过滤**：如 `2025-2026-1` 查看本学期评价
- **按评价者角色过滤**：选择「学生 / 督导 / 同行」查看某一类评价

每条评价包含：课程名称、授课教师、学期、评价者角色、分数（百分制）、文字评语、评价日期。

## 4. 教师使用指南

入口：首页 → 选择「教师」 → 选择你的身份 → 进入系统

### 4.1 仅本人课程

登录后，系统**自动**只展示你本人所授课程，无需手动筛选。这是服务端强制的权限控制——即使尝试伪造身份，系统也会拦截。

你可以看到：

- 我所授的全部课程列表
- 每门课程的基本信息（学分、学时、授课时间、教室）
- 全院统计数据（主任/督导可见的，教师不可见）

### 4.2 管理我的课程资源（Sprint2 核心）

这是教师端的核心功能。打开任意一门课程的详情弹窗，找到 📎 **教学资源**区：

#### 新增资源
1. 点击「➕ 新增资源」按钮
2. 在表单中填写：
   - **资源名称**（必填）：如「第 3 章 课件」
   - **资源类型**（必填）：课件 / 文档 / 视频 / 链接 / 作业
   - **资源链接**（必填）：必须以 http:// 或 https:// 开头
   - **资源说明**（可选）：简短描述
3. 点击「保存」，新资源会立即出现在列表顶部

#### 修改资源
1. 找到要修改的资源行，点击右侧「✏️ 编辑」
2. 修改后点击「保存」即可

#### 删除资源
1. 找到要删除的资源行，点击「🗑️ 删除」
2. 系统会弹出确认提示，确认后删除

> ⚠️ 权限说明：你只能管理**本人课程**的资源。如果你尝试对他人课程资源进行增删改，系统会返回 403 权限拒绝。主任和督导对你的资源仅有只读浏览权。

### 4.3 查看我的评价统计

页面下方「⭐ 我的课程评价统计」区域展示：

- **总体统计**：你的全部课程平均分数、总评价条数
- **分课程明细**：每门课程的评价条数、总均分、学生均分、督导均分、同行均分

> 🔒 你只能查看**本人**的评价统计。主任和督导可以查看任意教师的评价统计。

## 5. 问题排查

### 登录相关

| 现象 | 原因与解决 |
|------|-----------|
| 点击教师身份下拉框显示「加载中...」且无选项 | 后端服务未启动。请联系管理员确认服务运行状态 |
| 选择教师角色后无法进入 | 教师身份未选择。必须从下拉框中选一个身份 |
| 登录时报错「服务器内部错误」 | 数据库未初始化。请联系管理员运行 `npm run init-db` |

### 权限相关

| 现象 | 原因与解决 |
|------|-----------|
| 教师端想新增资源但没有表单 | 你当前身份不是该课程的授课教师，无写权限，属正常行为 |
| 督导/主任端想修改资源但按钮无效 | 督导和主任对资源仅有只读权限，属正常行为 |
| 尝试直接编辑 URL 越权访问他人课程 | 服务端会强制拦截并返回 403，页面会自动提示 |

### 数据相关

| 现象 | 原因与解决 |
|------|-----------|
| 搜索关键词「数据结构」没有结果 | 确认关键词拼写正确；通配符 `%` `_` `#` 会被转义，不会扩大匹配范围 |
| 课程详情显示 404 | 课程可能已被删除；也可能是非法 ID 格式（必须为大写 C+数字） |
| CSV 导出后 Excel 打开乱码 | 系统已处理 UTF-8 BOM，如仍乱码请确认 Excel 版本（2016+ 均正常） |

### 技术信息

- 平台数据存储在 SQLite 数据库文件（`data/teaching.db`），首次启动需运行 `npm run init-db`
- 全部请求使用 HTTPS Bearer Token 鉴权，Token 有效期为 24 小时
- 任何 401 未授权访问会自动跳回登录页
